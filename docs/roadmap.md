# Roadmap

Ideas for future work, roughly in the order they would most improve the plugin.
None of this is committed to a release, and nothing here is a promise.

The standard everything below is held to is the one in the README: **every number
is one git command away from being checked by hand, and none of them is a guess.**
A feature that cannot meet that does not belong here.

## Nothing is queued

Every entry this file held has landed, and each was retired in the pull request
that landed it. `CHANGELOG.md` is the record of what they turned into.

Known problems found while building those, and filed rather than guessed at, are
in the [issue tracker](https://github.com/moneycaringcoder/herdr-standup/issues)
instead: an observed defect belongs there, where it can carry the measurement
that found it, rather than here among ideas.
